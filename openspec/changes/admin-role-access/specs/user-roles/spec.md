# Spec Delta

## Purpose

引入管理员角色：区分普通用户与管理员，保护平台级设置（字典写、LLM 凭据）仅管理员可操作，并提供幂等的默认管理员账号。

## ADDED Requirements

### Requirement: 用户角色标记

每个用户 SHALL 具有角色标记（管理员/普通用户），普通用户为默认；当前用户信息接口 MUST 返回该标记。

#### Scenario: 新注册用户为普通用户

- **WHEN** 用户通过注册接口创建账号
- **THEN** 其角色为普通用户（非管理员）

#### Scenario: 当前用户信息包含角色

- **WHEN** 已登录用户请求当前用户信息
- **THEN** 响应中包含 `is_admin` 标记

### Requirement: 默认管理员账号

系统启动时 SHALL 幂等创建默认管理员账号 `admin@qq.com`（邮箱已验证，密码 `admin123`）；该账号已存在时 MUST NOT 覆盖或重置其任何字段。

#### Scenario: 全新环境创建默认管理员

- **WHEN** 数据库中不存在 `admin@qq.com` 时启动服务
- **THEN** 系统创建该管理员账号（邮箱已验证、角色为管理员），可用其密码正常登录

#### Scenario: 已存在时不覆盖

- **WHEN** `admin@qq.com` 已存在（包括已被修改过密码）时再次启动服务
- **THEN** 系统不做任何变更，现有凭据继续有效

### Requirement: 设置端点仅管理员可用

字典的写操作（新增、删除）与 LLM 设置的读、写操作 SHALL 仅允许管理员访问；非管理员访问时 MUST 返回 403 与错误码 `FORBIDDEN`。字典的读操作（按类型/全量）保持登录用户可读。

#### Scenario: 普通用户修改字典被拒绝

- **WHEN** 普通用户新增或删除字典项
- **THEN** 系统返回 403 与错误码 `FORBIDDEN`，且不产生任何变更

#### Scenario: 普通用户访问 LLM 设置被拒绝

- **WHEN** 普通用户读取或更新 LLM 凭据配置
- **THEN** 系统返回 403 与错误码 `FORBIDDEN`

#### Scenario: 管理员正常操作

- **WHEN** 管理员执行字典写操作或读写 LLM 设置
- **THEN** 系统正常处理并返回与既有契约一致的响应

#### Scenario: 字典读取保持开放

- **WHEN** 普通用户按类型读取字典选项
- **THEN** 系统正常返回（押题向导依赖此读取）

#### Scenario: 未登录访问设置端点

- **WHEN** 未携带有效访问令牌访问任一设置端点
- **THEN** 系统返回 401 与错误码 `UNAUTHORIZED`

### Requirement: 前端设置入口按角色控制

前端 SHALL 仅对管理员显示设置页入口；路由守卫 MUST 拦截非管理员对设置页的访问（重定向回首页）；非管理员直接访问设置相关接口时页面 MUST 展示 403 错误信息。

#### Scenario: 管理员可见设置入口

- **WHEN** 管理员登录后查看顶栏
- **THEN** 设置入口可见并可进入设置页

#### Scenario: 普通用户不可见设置入口

- **WHEN** 普通用户登录后查看顶栏
- **THEN** 设置入口不显示；直接输入 `/settings` 地址被路由守卫重定向回首页
